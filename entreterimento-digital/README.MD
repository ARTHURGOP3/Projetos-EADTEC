Proposta da atividade: Crie uma página HTML com o tema “Meu Portal de Entretenimento Digital”, dividida em três seções principais:

Filmes e Séries
Música e Podcasts
Games e Tecnologia
Cada seção deverá conter:

Um título (<h1> ou <h2>);

Duas a três imagens ilustrativas (usando <img>);

Pequenos textos explicativos (<p>).

Requisitos Técnicos

Utilize três tipos de CSS:

Inline (em pelo menos um elemento).

Interno (entre as tags <style> dentro de <head>).

Externo (arquivo .css linkado ao HTML).

Aplique os conceitos de classes e IDs para padronizar o estilo dos títulos e das fontes das imagens.

Use o modelo Flexbox para organizar as três seções lado a lado.

Inclua comentários no CSS, explicando partes importantes do código.

Crie um arquivo CSS Reset (baseado no modelo de Eric Meyer) e vincule-o antes da folha de estilo principal.
