# Agenda14_DS

Esse HTML cria uma página chamada “Atrativos Turísticos”, organizada em três colunas e 2 seções com Lugares Turísticos na cidade de São Paulo.


# Recursos usados no HTML: 
 
img → exibe imagens.

class → aplica estilos reutilizáveis.

id → aplica estilo específico. 

br → cria espaçamento entre os elementos.


# Objetivo da página: 

Criar um site de atrativos turísticos da cidade de São Paulo usando: HTML estrutural, CSS externo, o Css W3, imagens e organização em colunas.
