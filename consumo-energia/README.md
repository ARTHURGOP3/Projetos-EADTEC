Projeto: Cálculo de Consumo de Energia
==================================================================================================================================
Objetivo: Calcular o consumo médio diário do usuário e mostrar os resultados para ele
==================================================================================================================================
Fórmulas utilizadas:
Cálculo em kWh:(Potencia * Tempo * 30) / 1000
Cálculo em R$: (consumo_mensal*1.75)
==================================================================================================================================
Instruções para uso do progama:
Ao executá-lo é preciso informar os dados para o cálculo, como a potência, as horas de uso e para estruturação e organização da saída do programa o nome do aparelho.
