Projeto: Controle de Níveis de Água
==================================================================================================================================
Objetivo: Exibir alertas com cores diferentes conforme o nível de água, seguindo uma escala de risco.
==================================================================================================================================
Instruções para uso do progama:
Primeiro é necessário instalar a bibilioteca colorama vá para o terminal e digite:
pip install colorama
Depois só executar o código e fornecer os dados de 0-5
